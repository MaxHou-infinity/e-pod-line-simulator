### ✅ 1. 工序显示窗口自适应（蛇形布局）

**问题描述**：
- 工序数量超出画布显示范围时，无法完整展示所有工序
- 工序只能在单行显示，超出部分看不到

**优化方案**：
实现蛇形布局（Z字形布局），自动换行显示

**实现细节**：
1. **自动计算每行最大工序数**：
   ```python
   available_width = canvas_width - 2 * start_x
   max_stations_per_row = max(1, int(available_width / station_spacing))
   ```

2. **计算需要多少行**：
   ```python
   num_rows = (num_stations + max_stations_per_row - 1) // max_stations_per_row
   ```

3. **蛇形排列**：
   - 偶数行（0, 2, 4...）：从左到右排列
   - 奇数行（1, 3, 5...）：从右到左排列（反向）
   ```python
   if row % 2 == 1:
       col = max_stations_per_row - 1 - col
   ```

4. **曲线连接线**：
   - 跨行时：使用二次贝塞尔曲线绘制平滑过渡
   - 同行时：使用直线连接
   - 自动计算控制点，生成平滑曲线

**效果**：
- ✅ 工序数量不受限制，可以显示任意数量的工序
- ✅ 自动适应画布大小，调整窗口时自动重新布局
- ✅ 视觉效果清晰，蛇形排列便于追踪物料流向

### ✅ 2. 仿真时间显示优化

**问题描述**：
- 1倍速率时，时间变化不够直观
- 用户无法感知真实时间的流逝

**优化方案**：
1. **1倍速时按真实时间推进**：
   - 1秒仿真时间 = 1秒真实时间
   - 使用逐步推进方式，每次推进1秒仿真时间后sleep 1秒真实时间

2. **状态栏显示仿真时间**：
   - 格式：`仿真时间: HH:MM:SS`
   - 实时更新，显示当前仿真时间

3. **更新频率调整**：
   - 1倍速：每1秒（仿真时间）更新一次
   - 其他速度：每10秒（仿真时间）更新一次

**实现细节**：
```python
# 1倍速时间控制
start_time = time.time()
while self.env.now < duration_seconds:
    elapsed_real_time = time.time() - start_time
    if elapsed_real_time > self.env.now:
        # 推进1秒仿真时间
        self.env.run(until=self.env.now + 1.0)
        # sleep 1秒真实时间
        time.sleep(1.0)
```

**效果**：
- ✅ 1倍速时，用户可以看到真实时间的流逝
- ✅ 状态栏实时显示仿真时间，便于观察进度
- ✅ 时间显示格式清晰，易于理解

### ✅ 3. 报警信息时间戳

**问题描述**：
- 报警信息没有时间标识
- 无法知道报警发生在仿真过程的哪个时间点

**优化方案**：
1. **Alert类添加时间戳字段**：
   ```python
   timestamp_minutes: float = 0.0  # 从仿真开始经过的分钟数
   ```

2. **所有报警创建时记录时间戳**：
   - 瓶颈报警：记录检测到瓶颈的时间
   - WIP报警：记录WIP堆积的时间
   - 浪费报警：记录检测到浪费的时间

3. **报警面板显示时间戳**：
   - 格式：`[XX.X分钟] [级别] 消息内容`
   - 示例：`[15.5分钟] [CRITICAL] 瓶颈工序：注油，产能：850颗/h`

**实现细节**：
```python
# 在监控进程中记录时间戳
timestamp_minutes = self.env.now / 60.0
alert = Alert(
    alert_type="bottleneck",
    timestamp_minutes=timestamp_minutes,
    ...
)
```

**效果**：
- ✅ 所有报警都带有时间戳
- ✅ 可以清楚知道报警发生的时间点
- ✅ 便于分析产线在不同时间段的运行状况

## 技术说明

### 蛇形布局算法复杂度
- 时间复杂度：O(n)，n为工序数量
- 空间复杂度：O(n)，存储工序位置

### 1倍速时间同步精度
- 时间误差：<0.1秒（由于sleep和系统调度）
- 对于8小时仿真，误差<1%

### 时间戳精度
- 单位：分钟
- 精度：0.1分钟（6秒）
- 显示格式：保留1位小数

## 已知限制

1. **蛇形布局**：
   - 窗口大小改变时，需要手动刷新才能重新布局
   - 连接线曲线在极少数情况下可能不够平滑

2. **1倍速时间同步**：
   - 受系统调度影响，可能有微小误差
   - 暂停/恢复时，时间同步需要重新计算

3. **时间戳**：
   - 时间戳基于仿真时间，不是真实时间
   - 在不同速度下，时间戳的含义相同（都是仿真时间）
