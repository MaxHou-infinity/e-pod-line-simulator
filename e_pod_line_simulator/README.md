# 电子烟产线仿真优化工具

> 仓库总览、快速开始与项目价值见根目录 [README.md](../README.md)。

## 项目简介

这是一个基于 SimPy 的离散事件仿真工具，用于电子烟产线的设计和优化。

**核心价值**：让产线优化从"2 周试错"变成"2 小时仿真"。

## 主要功能

1. **产线配置管理**：工序增删改、JSON 保存/加载、Excel 批量导入
2. **离散事件仿真**：基于 SimPy，支持并联/协同模式、WIP 缓冲区、堵塞/等待
3. **2D 可视化**：蛇形布局自适应换行，显示物料流向和 WIP
4. **瓶颈识别与报警**：瓶颈/资源浪费/WIP 堆积三类报警，带仿真时间戳
5. **KPI 实时监控**：瓶颈产能、日产量、日成本、单颗成本、产线平衡率、UPPH
6. **方案对比**：保存 2-5 个配置方案，对比 7 项 KPI 并推荐最优方案
7. **切换事件**：仿真运行中可触发工序切换（默认停机 45 分钟），观察上下游影响
8. **报告导出**：将 KPI、报警、WIP 采样、切换事件导出为 Excel/PDF
9. **画布交互**：拖拽排序、双击编辑、右键菜单（编辑/删除/触发切换）
10. **快速配置向导**：模板 → 数据来源 → 班次 → 一键仿真
11. **统一视觉与交互（V1.2）**：设计令牌主题、节点卡片/瓶颈徽标、KPI 卡片、
    报警图标、空状态引导、运行状态徽标、快捷键、脏状态确认、Tooltip
12. **报警一键复制 + 术语速查**：报警面板一键复制全部报警文本；
    配置面板/向导/帮助菜单可查看供应链关键术语说明
13. **生产类型模板（V1.3）**：烟弹组装 / 烟油灌装 / 尼古丁袋高速包装
14. **批量与配方（V1.3）**：Recipe/Batch/Tank、批次过程仿真、CIP/SIP 清洗切换
15. **机台节拍与人力模型（V1.3）**：machine_takt、工种/技能矩阵/洁净区上限
16. **质量门与扩展 KPI（V1.3）**：在线检测/批次放行、批次周期/收率/元每升/元每袋
17. **统一浅色主题与 2026 桌面美学（V3.0）**：圆角/阴影/网格、
    Toast 反馈、键盘可达、命令面板（Ctrl+K）、报警栏折叠筛选
18. **智能报警与评估（V3.1）**：建议按工序类型分流、WIP 失衡方向、
    报警去重升级、饥饿/堵塞报警、工序级指标、预测预警、敏感性试算、失衡报告

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 0. 普通用户启动（免命令行）

不需要打开终端，直接双击：

- **macOS**：双击 `启动.command`。首次启动会提示安装依赖，安装完成后自动打开程序；
  如系统提示"无法打开"，请在访达中右键该文件 → 打开。
- **Windows**：双击 `启动.bat`，首次运行自动安装依赖后启动程序。

适合不想接触命令行、直接使用工具的 IE 工程师/车间用户。

### 0.1 从压缩包安装使用

1. 解压 `E-Pod-Line-Simulator-v3.0.0.zip`；
2. 进入 `e_pod_line_simulator` 目录；
3. macOS 双击 `启动.command`，Windows 双击 `启动.bat`；
   首次运行会自动安装依赖并启动程序；
4. 如使用命令行：`pip install -r requirements.txt` → `python run.py`。

### 2. 运行程序

```bash
python run.py
```

或者：

```bash
cd src
python main.py
```

### 3. 使用步骤

1. **创建产线**：点击"文件" → "新建产线"
2. **添加工序**：点击"添加"按钮，输入工序参数（也可通过 Excel 导入）
3. **运行仿真**：点击"开始仿真"按钮，选择速度倍数
4. **查看结果**：观察画布瓶颈高亮、报警面板和 KPI 仪表盘
5. **优化调整**：根据建议调整参数，保存多个方案后使用"分析 → 方案对比"

## 配置说明

### JSON 配置文件格式

| 字段名 | 类型 | 描述 | 示例值 |
|--------|------|------|--------|
| name | string | 产线名称 | "电子烟产线_标准版" |
| shift_hours | int | 班次时长（小时） | 8 |
| break_minutes | int | 休息时间（分钟） | 60 |
| worker_hourly_wage | float | 工人时薪（元/小时） | 20.0 |
| stations | array | 工序列表 | [{}, {}, ...] |

### 工序配置字段

| 字段名 | 类型 | 描述 | 示例值 |
|--------|------|------|--------|
| id | string | 工序唯一 ID | "s01" |
| name | string | 工序名称 | "注油" |
| process_time | float | 单颗耗时（秒） | 25 |
| worker_count | int | 工人数量 | 2 |
| collaboration_type | string | 协作模式（parallel/collaborative） | "parallel" |
| oee | float | 设备综合效率（0-1） | 0.85 |
| efficiency | float | 人员效率（0-1） | 0.95 |
| changeover_time | int | 切换时间（分钟） | 45 |
| buffer_capacity | int | 缓冲区容量 | 100 |

**日成本计算说明**：日成本 = 总人数 × 工人时薪 × 班次时长（不扣减休息时间）；
日产量 = 瓶颈产能 × 有效工时（班次时长 - 休息时间）。
配置入口：主界面底部「班次配置」按钮（设置班次时长、休息时间、时薪）。

**计量单位说明（V1.3）**：计量单位随生产类型自动切换——烟弹组装 = 颗、
烟油灌装 = 升、尼古丁袋 = 袋。KPI 仪表盘、画布、报告、方案对比同步显示对应单位。

**工序编辑字段映射（V1.3）**：
- 机台节拍：仅尼古丁袋
- 清洗时间（CIP/SIP）：仅烟油灌装
- 抽检比例 / 缺陷率 / 返工时长：烟油灌装与尼古丁袋
- 烟弹组装：以上字段均不显示

## 常见问题

**Q: 如何添加新工序？**

A: 点击配置面板的"添加"按钮，输入工序参数即可；批量添加可先下载
`configs/产线配置模板.xlsx` 填写后通过"文件 → 导入 Excel"。

**Q: 仿真速度如何调整？**

A: 在控制按钮区域选择速度倍数（1x/2x/8x/16x/32x/64x）。

**Q: 如何对比多个方案？**

A: 配置好产线后点击"保存方案"，至少保存 2 个方案，然后通过
"分析 → 方案对比"查看 KPI 对比和推荐结果。

**Q: 如何导出报告？**

A: 通过"分析 → 导出报告"，选择 Excel 或 PDF 格式；未运行仿真时会先
用当前配置自动仿真一次。

**Q: 如何模拟切换停机？**

A: 开始仿真后，右键工序节点选择"触发切换..."，或通过"仿真 → 触发切换..."。

**Q: 日成本是怎么计算的？**

A: 日成本 = 总人数 × 时薪 × 班次时长（元/天）。修改入口在底部
"班次配置"按钮；KPI 卡片悬停可查看公式提示。

**Q: 看不懂专业术语怎么办？**

A: 点配置面板右上角"术语?"，或"帮助 → 术语说明"，或快速配置向导
第一步的"术语速查"，均可查看术语与意义梗概。

**Q: 如何识别瓶颈？**

A: 瓶颈会自动识别并高亮显示，同时显示在报警面板中。
