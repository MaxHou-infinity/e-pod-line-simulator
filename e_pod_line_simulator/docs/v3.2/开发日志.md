- 目标：罐容不足时批次等待并报警，禁止静默丢弃；成品罐按灌装线
  产能持续消耗。

  - [x] 新增罐消耗进程：按首工序（灌装）产能持续从成品罐取液
  - [x] 全量 pytest 全绿（97 passed）
