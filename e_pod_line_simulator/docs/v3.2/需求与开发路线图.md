# V3.2 人力规划与多业态深化：需求与开发路线图（正式版）

> 版本：v3.2.0 立项文档（原 V4.0 立项，经用户决策调整为 V3.2）
> 制定日期：2026-08-11
> 基线：v3.1.0（tag `v3.1.0`）
> 立项方式：主控 Agent 代码/功能/交互盘点 + HRBP/HR 受众需求输入

## 一、背景与目标

V3.1 已具备三业态模板（烟弹组装 / 烟油灌装 / 尼古丁袋高速包装）、
智能报警与评估（瓶颈/WIP/饥饿/堵塞/预测）、敏感性试算、失衡分析与
多 Sheet 报告。当前主要受众为 **IE 工程师、产线经理、精益顾问**。

V3.2 围绕两个增长点展开：

1. **三业态业务深度**：把“可仿真的模板”推进到“贴近行业真实模型”，
   补齐组装 BOM/缺料、烟油罐容/批次排产/CIP 周期、尼古丁袋换型/
   OEE 分解/包装下游等行业关键语义；
2. **人力规划决策（新增受众 HRBP/HR）**：从“按工序配人”升级为
   “按业务目标与预算配人”，用仿真输出人力需求、排班、成本、
   招聘缺口与爬坡达产预估。

配套评估与自动化迭代（KPI 历史趋势、批量试算、敏感性扩展、
AI 自动优化、平台打包）作为 P1/P2 纳入本版路线。

## 二、用户画像与典型场景

| 用户 | 典型场景 | 核心诉求 |
|------|----------|----------|
| IE 工程师 | 新线平衡、瓶颈优化 | 参数 → 产能 / 线平衡 / 优化建议 |
| 产线经理 | 达产与排产 | 换型、维护、班次对产出的影响 |
| 精益顾问 | 对标与改善 | 失衡分析、敏感性试算、报告 |
| HRBP / HR | 年度人力预算、新线投产人力测算、产能爬坡人力计划、人效对标 | 目标产量 → 岗位 / 人数 / 成本 / 招聘缺口 |

## 三、V3.1 现状盘点与缺口

### 3.1 已有资产（可直接复用）

- 生产类型模板与计量单位联动（颗 / 升 / 袋）
- 工序模型：并联/协同、OEE、人员效率、机台节拍、工种、
  洁净区、质量门（抽检/缺陷/返工）、CIP/SIP 清洗
- 产线模型：班次/休息/时薪、`labor_config`、`skill_matrix`、
  `cleanroom_limits`、Recipe / Batch / Tank
- 仿真引擎：WIP 缓冲、饥饿/堵塞、批次过程（调配→陈化→灌装→QC→放行）、
  station_metrics、稳态预热
- 评估：瓶颈/WIP/预测报警、敏感性试算（+1 人 / OEE+5% / 节拍-1s）、
  失衡分析 Sheet
- 交付：Excel 9 Sheet + PDF 报告、5 方案对比、Release 自动打包

### 3.2 缺口（本版路线图输入）

| 维度 | 缺口 |
|------|------|
| 烟弹组装 | 无 BOM/多部件配套、无组件缺料报警、无返修/测试工位语义 |
| 烟油灌装 | 罐容不足时行为未定义（当前静默丢弃）；无多配方批次排产序列；无周期性 CIP（仅换配方清洗）；无原料到货/库存；放行/隔离粒度不足 |
| 尼古丁袋 | 无包装材料供料（膜/盒/箱）；无多规格换型排序；无装箱/码垛下游；无 OEE 三要素分解（A/P/Q） |
| 通用 | 无多班次排班、无设备故障（MTBF/MTTR）与维护计划、无 BOM 成本、无换型顺序优化（SMED） |
| 人力 | `labor_config`/`skill_matrix` 仅校验未参与决策；无目标产量反推人力；无爬坡/缺勤/离职/招聘到岗；无 HR 报表 |
| 评估 | 敏感性仅瓶颈单变量；无跨运行历史趋势；无批量自动试算；无 AI 寻优；无 PyInstaller 平台打包 |

## 四、三业态深化需求

### 4.1 烟弹组装深化（P1）

- **BOM 与配套**：装配工序可定义组件清单（棉芯/发热丝/外壳/烟油等），
  组件按消耗速率供料；
- **组件缺料报警**：组件库存低于阈值时报警，下游工序饥饿；
- **返修回路**：测试不良件进入返修工位（复用 `rework_minutes`），
  返修产出重新入线。

验收：BOM 缺料可触发报警且下游饥饿可复现。

### 4.2 烟油灌装深化（P0）

- **罐容约束**：成品罐液位达到上限时批次灌装等待，不得静默丢弃；
  提供满罐等待/报警；
- **批次排产序列**：多配方批次按顺序执行，换配方触发 CIP；
  支持陈化罐组并行（多个批次同时陈化）；
- **周期性 CIP**：按运行时长或批次数触发清洗（可配置阈值）；
- **原料与库存**：原料到货计划、投料消耗、缺料阻塞；
- **放行/隔离**：QC 未放行批次不计入可发运产出。

验收：500L 批次 × 2 配方切换场景下，罐容约束与 CIP 序列可复现，
无静默丢弃。

### 4.3 尼古丁袋高速包装深化（P1）

- **换型矩阵（SMED）**：口味/浓度/包装规格切换时长矩阵，
  换型顺序影响总停机；
- **包装材料供料**：膜/盒/箱按消耗速率供料，缺料报警；
- **下游工序**：装箱、码垛；
- **OEE 三要素分解**：可用率 × 性能率 × 合格率（A/P/Q），
  故障、换型、清洗分项统计。

验收：换型序列下 OEE 分解与总产出一致。

### 4.4 通用能力增强（P1/P2）

- 多班次（1/2/3 班）、班次日历与加班；
- 设备故障模型（MTBF/MTTR）与维护窗口；
- BOM 原料成本进入单位成本；
- 换型顺序优化建议（贪心/SMED 排序）。

## 五、HRBP/HR 人力规划模块（P0，本版重点）

### 5.1 目标

把“按工序配人”升级为“按业务目标与预算配人”，输出 HR 可直接
使用的**人力需求、排班、成本、招聘缺口与爬坡达产预测**。

### 5.2 需求规格

1. **目标产量反推人力**：输入日产量目标 → 按瓶颈与工序利用率反推
   各工序、各工种人数（并联/协同规则复用）；
2. **多班次与排班**：班次数、班次时长、休息、加班 → 有效工时与
   人力覆盖；
3. **人力成本模型**：基本工资/时薪、加班系数、社保与福利比例、
   招聘成本、培训成本、缺勤率、离职率（月）；
4. **技能矩阵与多能工**：跨工种可互换 → 柔性人力评估（减少
   瓶颈等待的收益对比）；
5. **爬坡模型**：新员工效率曲线（0-90 天按比例爬坡）、产能爬坡
   计划 → 达产天数；
6. **招聘计划**：输入到岗时间与数量 → 按周人力缺口时间线；
7. **人效看板**：UPPH 对标、人力利用率（运行/等待占比）、人时成本；
8. **HR 报表**：人力需求表（工序 × 工种 × 班次）、人力成本预算、
   人时汇总、招聘缺口、爬坡达产预测；Excel 新增人力 Sheet + PDF 摘要。

### 5.3 新增 KPI

| KPI | 说明 |
|-----|------|
| 人力需求 | 目标产量下的总人数 / 分岗位人数 |
| 人时 | 总人数 × 有效工时（人·小时/班） |
| 人力成本 | 含加班/社保/招聘/培训的日、月成本 |
| 单位人力成本 | 人力成本 ÷ 产出（元/单位） |
| 人力利用率 | 实际加工人时 ÷ 在岗人时 |
| 招聘缺口 | 需求人数 − 当前在岗 − 已计划到岗（按周） |
| 达产天数 | 按爬坡曲线达到目标日产量的天数 |

### 5.4 交互入口

- 菜单新增「人力规划」：向导式（产量目标 → 班次 → 成本参数 →
  技能/爬坡 → 结果）；
- KPI 面板新增人力卡片组；结果页含人力缺口时间线；
- 快速配置向导增加“按产量目标生成”分支。

## 六、评估与智能迭代（P1/P2）

- **P1 KPI 历史趋势**：跨运行记录，趋势表/图（延续既有 P2 遗留）；
- **P1 批量试算**：人力/班次/节拍参数网格自动仿真对比；
- **P1 敏感性扩展**：多岗位加减人、自动化替代（机台数）、原料价格；
- **P2 AI 自动优化**：遗传算法寻优（人数/缓冲/节拍），输出 TOP 方案
  （承接原 V1.4 既定项）；
- **P2 平台打包**：PyInstaller（macOS/Windows），随 Release 交付。

## 七、里程碑与 Loop 计划

- **M1（模型层）**：人力规划数据模型（目标产量/班次/成本/爬坡/
  招聘）+ 罐容/批次排产 + 版本登记 v3.2.0；
- **M2（引擎层）**：爬坡/班次/故障/换型/OEE 分解 + 批量试算 +
  敏感性扩展；
- **M3（展示层）**：人力规划向导/看板/HR 报告 + KPI 趋势 +
  全量验收与发布。

每个 Loop 沿用 `docs/v1.1/开发日志模板.md`，记录目标、验收标准、
实际执行、验证结果、成功/失败根因、文档同步与遗留事项。

## 八、验收标准（P0 必达）

1. 目标产量 → 人力需求：与手工测算误差 < 5%；
2. 多班次/加班/缺勤/离职参数生效，成本可复现；
3. 罐容约束生效：满罐不再静默丢弃，触发等待/报警；
4. 换配方 CIP 与周期性 CIP 可配置，并计入 OEE/成本；
5. HR 报告导出包含人力需求、成本、缺口与爬坡预测；
6. V3.1 JSON 配置向后兼容可加载；
7. pytest 全绿，核心模块覆盖率 ≥80%，GUI 冒烟通过；
8. 版本号 v3.2.0 + tag + 文档/日志同步。

## 九、范围边界与风险

- **不做**：合规约束建模（沿用 V1.3 决策）、招聘系统/HRIS 集成、
  Web 化（V2.0 另行立项）；
- 人力需求为规划估算，不构成用工承诺，HR 需结合现场验证；
- 结果依赖输入参数质量：默认值来自模板，用户可覆盖。
