# 方案对比功能设计文档

## 一、功能需求分析

### 核心需求
1. **保存方案**：将当前产线配置保存为命名方案
2. **管理方案**：查看、删除已保存的方案
3. **对比方案**：选择多个方案进行KPI对比
4. **显示差异**：计算并显示方案间的差异
5. **推荐方案**：根据优化目标推荐最佳方案

### PRD要求
- 支持保存至少5个方案
- 对比表格显示关键KPI
- 显示方案间的差异（绝对值和百分比）
- 可导出对比报告（后续实现）

---

## 二、实现策略

### 策略1：轻量级内存方案（推荐⭐⭐⭐⭐⭐）

**核心思路**：
- 方案保存在内存中（程序运行期间）
- 使用简单的数据结构存储方案快照
- 对比时实时计算KPI

**优点**：
- ✅ 实现简单，代码量少
- ✅ 性能好，无需文件IO
- ✅ 适合快速迭代

**缺点**：
- ⚠️ 程序关闭后方案丢失（但可以手动保存为JSON）

**适用场景**：单次使用，快速对比

---

### 策略2：持久化存储方案（备选⭐⭐⭐）

**核心思路**：
- 方案保存到JSON文件
- 程序启动时加载已保存的方案
- 支持跨会话使用

**优点**：
- ✅ 方案持久化
- ✅ 可以分享方案文件

**缺点**：
- ❌ 实现复杂，需要文件管理
- ❌ 需要处理文件冲突

**适用场景**：需要长期保存方案

---

## 三、推荐方案：轻量级内存方案

### 设计理由
1. **符合使用场景**：用户通常在单次会话中对比方案
2. **实现简单**：快速上线，后续可扩展
3. **性能好**：无需文件IO，响应快
4. **易于维护**：代码简单，bug少

### 后续扩展
- 如果用户需要持久化，可以添加"导出方案"功能
- 将方案导出为JSON，下次可以导入

## 四、数据模型设计

### 1. Scenario（方案）类

```python
@dataclass
class Scenario:
    """
    方案类 - 存储产线配置的快照
    
    包含：
    - 产线配置（ProductionLine对象）
    - 方案名称
    - 创建时间
    - 方案描述（可选）
    """
    name: str  # 方案名称，如"方案A"、"优化方案"
    production_line: ProductionLine  # 产线配置快照
    created_at: str  # 创建时间（格式化字符串）
    description: str = ""  # 方案描述（可选）
    
    def get_kpis(self) -> Dict[str, float]:
        """计算并返回所有KPI指标"""
        return {
            'total_workers': sum(s.worker_count for s in self.production_line.stations),
            'bottleneck_capacity': self.production_line.get_bottleneck_capacity(),
            'daily_output': self.production_line.calculate_daily_output(),
            'total_cost': self.production_line.calculate_total_cost(),
            'unit_cost': self.production_line.calculate_unit_cost(),
            'balance_rate': self.production_line.calculate_line_balance_rate(),
            'upph': self.production_line.calculate_upph()
        }
```

### 2. ScenarioManager（方案管理器）类

```python
class ScenarioManager:
    """
    方案管理器 - 管理所有保存的方案
    
    功能：
    - 保存方案
    - 删除方案
    - 获取方案列表
    - 对比方案
    """
    def __init__(self):
        self.scenarios: Dict[str, Scenario] = {}  # 方案字典，key为方案名
    
    def save_scenario(self, name: str, production_line: ProductionLine, description: str = "") -> bool:
        """保存方案"""
        
    def delete_scenario(self, name: str) -> bool:
        """删除方案"""
        
    def get_scenario(self, name: str) -> Optional[Scenario]:
        """获取方案"""
        
    def list_scenarios(self) -> List[str]:
        """获取所有方案名称"""
        
    def compare_scenarios(self, scenario_names: List[str]) -> Dict[str, Any]:
        """对比多个方案的KPI"""
```

## 十二、技术难点和解决方案

### 难点1：方案快照的深拷贝
**问题**：直接引用ProductionLine会导致后续修改影响已保存的方案

**解决方案**：
```python
# 使用深拷贝保存快照
import copy
scenario = Scenario(
    name=name,
    production_line=copy.deepcopy(production_line),  # 深拷贝
    ...
)
```

### 难点2：对比表格的显示
**问题**：Tkinter的Treeview样式定制有限

**解决方案**：
- 使用ttk.Treeview，支持基本样式
- 差异用颜色标记（绿色/红色）
- 如果样式不够，可以用Canvas自定义绘制

### 难点3：推荐算法的设计
**问题**：如何判断哪个方案最优？

**解决方案**：
- 提供多个优化目标（成本、产能、平衡率）
- 默认推荐单颗成本最低的方案
- 用户可以自定义优化目标
