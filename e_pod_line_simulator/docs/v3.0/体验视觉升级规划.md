# V3.0 体验与视觉升级专项（规划）

> 制定日期：2026-08-11
> 基线：V1.3.0（tag `v1.3.0`）
> 版本登记：V3.0.0（开发启动时执行 `src/version.py` 更新与 tag）

## 一、背景与目标

在 V1.3.0 功能稳定的基础上，本阶段**只做体验升级**：

1. 提升操作体验、视觉体验、交互体验；
2. 美学对齐 2026 年最新桌面应用（参照 Codex / Claude desktop）；
3. **不做**产品逻辑、功能的进一步开发，**不做**破坏性变革。

## 二、范围边界（硬性约束）

**不做**：
- 新增/修改仿真逻辑、数据模型、业务 KPI
- 改变生产类型模板、配方/批次/质量门等既有功能语义
- 破坏性重构（不重写 GUI 框架，不迁移 Web/Electron）
- 修改 PRD 原文

**做**：
- 视觉体系升级（设计令牌 2.0、统一浅色主题、组件视觉规范）
- 交互体验升级（聚焦态、悬停、键盘可达、微反馈、布局打磨）
- 纯展示层与事件层的非破坏性调整

## 四、2026 桌面美学参照（Codex / Claude desktop）

### 4.1 参照特征

- **表面层次**：背景 / 卡片 / 浮层三级层次，卡片圆角 12-16px，弱阴影
- **主题**：克制浅色主题：中性底 + 高对比文本
- **颜色**：克制的主色（蓝/紫），状态色语义化，禁用态低对比
- **字体**：系统字体 + 清晰字阶（12/13/15/17/20），行高 1.4-1.6
- **动效**：150-200ms 过渡，悬停/按下/聚焦有微反馈，不做花哨动画
- **信息密度**：留白优先，一屏一个主任务
- **输入与反馈**：清晰聚焦环、即时校验提示、Toast 级反馈

### 4.2 与当前差距

| 维度 | 当前 | 目标 |
|------|------|------|
| 圆角/阴影 | 节点有圆角，面板/对话框为系统直角 | 统一 10-16px 圆角 + 弱阴影令牌 |
| 主题 | 仅亮色 | 统一浅色主题与克制配色 |
| 聚焦态 | 基本无 | 主色聚焦环、悬停高亮 |
| 动效 | 无 | 150-200ms 过渡（可用 `after` 实现） |
| 布局 | 三栏可用但视觉密度偏高 | 统一间距刻度、优化留白与分组 |
| 图标 | emoji 混合 | 统一符号集（几何图标 + 语义色） |
| 反馈 | 状态栏文字为主 | Toast / 徽标 / 按钮状态反馈 |

## 五、设计规范设定（Design Tokens 2.0）

### 5.1 新增令牌（`theme.py` 扩展）

```text
RADIUS = { sm: 8, md: 12, lg: 16 }
SHADOW = { card: (0,1,2,rgba), popup: (0,4,12,rgba) }
MOTION = { fast: 120ms, normal: 180ms }
THEMES = { light: {...}, dark: {...} }
```

### 5.2 组件规范

- **主窗口**：三栏布局保持，面板统一 surface/border 令牌
- **卡片**（KPI/节点/方案）：圆角 12、边框 1、浅阴影
- **按钮**：主/次/危险三级，悬停加深、按下内缩、禁用降对比
- **输入框**：聚焦主色环、错误红环 + 提示
- **对话框**：圆角 14、居中阴影、统一标题/按钮间距
- **报警栏**：级别色条 + 图标 + 折叠/清空入口
- **画布**：网格底纹（浅色）、节点阴影、连接线平滑

## 六、交互体验提升清单

### P0（发布门槛）

1. 统一浅色主题与克制配色（深色模式已取消）
2. 全局聚焦环与键盘可达性（Tab 顺序、Enter 确认、Esc 关闭）
3. 按钮/节点/输入框悬停与按下反馈
4. 空状态与结果反馈升级（Toast 而非仅状态栏）

### P1（应做）

5. 对话框与向导视觉统一（圆角/间距/步骤高亮）
6. 画布微交互（节点悬停放大 1.02、瓶颈徽标呼吸提示）
7. 报警栏可折叠、可清空、级别筛选
8. 列表/表格斑马纹与选中态

### P2（可做）

9. 键盘命令面板（Ctrl+K 快速跳转）
10. 启动页/欢迎屏（最近打开、模板入口）
11. 动效节流与无障碍对比度检查

## 八、验收标准

1. 统一浅色主题，全部界面无颜色/对比度硬伤
2. 2026 桌面美学特征落地：圆角/阴影/字阶/留白/微交互
3. 键盘可达：Tab/Enter/Esc 可完成核心流程
4. 关键操作有即时反馈（Toast/按钮态/聚焦环）
5. 产品逻辑零变更：pytest 全绿、仿真结果与 V1.3 一致
6. GUI 冒烟通过；文档同步；tag `v3.0.0`

## 九、风险与应对

| 风险 | 应对 |
|------|------|
| Tkinter 动效/圆角能力有限 | 用 after 过渡与多边形圆角，不做原生动画框架 |
| 按钮配色对比度问题 | 克制配色令牌 + 对比度检查 |
| 视觉改动引入回归 | 每个 Loop pytest + GUI 冒烟 |
| 范围蔓延（功能/Web） | 硬性排除项，评审把关 |
