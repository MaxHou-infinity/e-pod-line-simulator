# V1.3 产品形态扩展：烟油与尼古丁袋

## 需求与开发路线图（正式版）

> 版本：v1.3.0 立项文档
> 制定日期：2026-08-10
> 基线：v1.2.0（已交付，tag `v1.2.0`）

## 一、背景与目标

当前工具（V1.2.0）主要适配**电子烟烟弹的离散组装**：串行工序、以"颗"计件、
人工/半自动密集、优化人力配置与线平衡。

V1.3 目标：在不推翻现有架构的前提下，扩展支持两类新生产形态：

1. **烟油（e-liquid）**：液体化工/连续-批量混合形态；
2. **尼古丁袋（nicotine pouch）**：高速自动化包装 + 食品/医药级 GMP 形态。

核心思路：引入**生产类型模板（Production Type）**，把"组装 / 灌装 / 高速包装"
统一到同一仿真框架，按类型启用不同模型、字段、KPI 与合规约束。

## 二、产品形态对比（需求输入）

| 维度 | 烟弹组装（现状） | 烟油（V1.3） | 尼古丁袋（V1.3） |
|------|------------------|--------------|------------------|
| 过程形态 | 离散串行装配 | 配方/批量：调配→均质→陈化→灌装→封口→QC | 高速机台：混合→填充→密封→包装→在线检测 |
| 计量单位 | 颗 | 升 / kg / 批次 | 袋 / 包 / 批次 |
| 缓冲 | WIP（颗） | 罐容 / 管路 | 线内缓冲（包/袋） |
| 切换 | 口味切换 45 分钟 | CIP/SIP 清洗 + 换配方 + 首件确认 | 换口味/浓度 + 清洗 + 首件确认 |
| 人力 | 按工序人数 | 调香师、灌装操作员、QC 化验员、清洗工 | 产线节拍 × 工位数、包装机手 |
| 质量 | 瓶颈/堵塞报警 | 批次合格率、一次合格率、收率、放行门 | 在线重量/密封/尼古丁含量抽检 |
| 合规 | 无 | GMP 洁净等级、批次追溯 | GMP、SNI/BPOM 认证、尼古丁上限 |

## 三、需求规格

### 3.1 生产类型模板（P0）

- 新增枚举 `ProductionType`：`assembly` / `liquid_filling` / `pouch_packaging`
- 产线/工序/向导/导入模板按类型切换字段：
  - assembly：现状字段（颗、WIP、协作模式）
  - liquid_filling：批次量、罐容、配方、清洗时长、收率
  - pouch_packaging：机台节拍、工位数、在线检测站、包装规格
- 配置校验按类型启用（错误字段在 GUI 隐藏/禁用）

### 3.2 批量与配方模型（P0）

- 新增 `Recipe`：配方名称、原料清单与比例、尼古丁浓度、口味变体、批次追溯号
- 新增 `Batch`：批次量、计划开始/结束、状态（调配/陈化/灌装/QC/放行）
- 新增 `Tank`：罐容、当前液位、清洗状态（CIP/SIP）
- `ProductionLine` 兼容：装配线使用 Station，批量线使用 BatchStep + Tank

### 3.3 过程仿真扩展（P0）

- 批量过程：调配→均质→陈化（可并行批次）→灌装→封口→QC 放行
- 清洗切换：切换时间 = CIP/SIP 清洗 + 换配方 + 首件确认（替代固定 45 分钟）
- 机台节拍：尼古丁袋按"机台节拍 × 工位数"建模，支持高速包装线
- 收率/损耗：每批次按配方收率折算，损耗进入成本与排产
- 质量门：在线检测站按抽检比例触发，未过门批次进入返工/隔离

### 3.4 人力模型扩展（P0/P1）

- 新增工种：调香师、灌装线操作员、QC 化验员、包装机手、清洗工
- 技能矩阵：哪些工种可互换（如清洗工与灌装操作员培训后互换）
- 洁净区人数上限：GMP 洁净等级（A/B/C/D）约束单区人数
- 人力规则：
  - 烟油：批次任务 × 人数 + 化验/放行人力
  - 尼古丁袋：产线节拍 × 工位数

### 3.5 质量与合规约束（P0/P1）

- 合规输入项（以最新法规为准，本版内置默认值并允许修改）：
  - 印尼 SNI 9070-2022：尼古丁袋 ≤ 16.6 mg/袋
  - 烟油尼古丁上限：游离态 ≤ 20 mg/ml，尼古丁盐 ≤ 60 mg/ml
  - BPOM：每个口味/浓度/配方变体需单独认证，未认证不得生产
  - GMP 洁净车间：未通过审核前员工须完成 GMP 培训方可入岗
- 仿真行为：合规不达标 → 报警/阻塞；批次追溯号贯穿全流程
- 报告：新增合规检查项与追溯清单

### 3.6 KPI 与报告（P1）

- 新增 KPI：批次周期、批次合格率、一次合格率、收率、
  清洗时间占比、元/升、元/袋、机台 OEE
- 报告导出扩展：配方/批次/质量门/合规检查 Sheet

### 3.7 数据与导入导出（P1）

- Excel 模板扩展：生产类型、配方、批次、罐、质检字段
- JSON schema 扩展并保持向后兼容（旧配置可加载）
- 快速配置向导：第一步增加"生产类型"选择（组装/灌装/高速包装）

### 3.8 可视化（P2）

- 流程型布局：罐 → 管线 → 灌装机 → 封口 → QC
- 批次甘特图；质量门状态显示；清洗状态高亮

## 四、验收标准（P0 必须满足）

1. 三种生产类型模板可切换，字段按类型显示/校验
2. 烟油单批次仿真：结果与手工计算误差 < 3%
3. 尼古丁袋机台节拍仿真：产出/人力符合节拍 × 工位模型
4. CIP/SIP 清洗切换生效，切换时间可配置
5. 合规硬约束（SNI/BPOM/GMP）触发报警或阻塞
6. 人力模型支持工种、技能互换、洁净区人数上限
7. 报告与 KPI 包含批次/收率/合规新增项
8. pytest 全绿；核心模块覆盖率 ≥80%；GUI 冒烟通过
9. 版本号统一 v1.3.0，文档同步，发布 tag `v1.3.0`

## 六、依赖与风险

| 风险 | 应对 |
|------|------|
| 批量过程使 SimPy 模型复杂化 | 批次按进程 + 事件建模，先 headless 验证再接入 GUI |
