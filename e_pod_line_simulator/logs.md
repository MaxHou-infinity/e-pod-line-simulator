### 技术细节

**蛇形布局算法**：
- 计算每行最大工序数：`max_stations_per_row = (canvas_width - 2*start_x) / station_spacing`
- 计算行数：`num_rows = (num_stations + max_stations_per_row - 1) // max_stations_per_row`
- 奇数行反向：`if row % 2 == 1: col = max_stations_per_row - 1 - col`

**1倍速时间控制**：
- 使用time.time()记录真实时间
- 每次推进1秒仿真时间后sleep 1秒真实时间
- 确保仿真时间与真实时间同步

**曲线连接线**：
- 跨行时使用二次贝塞尔曲线绘制平滑过渡
- 同行时使用直线连接
- 自动计算控制点生成平滑曲线

## 2024-01-15 - 新增UPPH指标

### 新增功能

**UPPH（Units Per Person per Hour）指标**
- 功能：添加人均效率指标UPPH，用于衡量单位时间内每人能生产的成品数量
- 计算公式：UPPH = 瓶颈产能 / 总工人数（颗/人·小时）
- 显示位置：KPI仪表盘，新增第6列显示
- 显示格式：保留1位小数，单位"颗/人·h"

**UPPH的意义**：
- 衡量人均产出效率：数值越高，说明人力利用效率越高
- 评估产线设计合理性：UPPH过低可能表示人力配置不合理
- 跟踪培训效果：UPPH提升说明员工技能提升或流程优化
- 典型范围：电子烟行业UPPH通常在30-80颗/人·小时

### 修改的文件

- `src/models.py`
  - `ProductionLine.calculate_upph()`：新增UPPH计算方法
  - 计算公式：瓶颈产能 / 总工人数
  - 包含完整的文档注释和示例说明

- `src/gui_panels.py`
  - `KPIDashboard._create_widgets()`：KPI列表从5列扩展到6列
  - `KPIDashboard.update_kpis()`：添加UPPH更新逻辑
  - 显示格式：保留1位小数

- `src/gui_main.py`
  - `_update_kpi()`：添加UPPH计算和更新调用

### 技术细节

**UPPH计算公式选择**：
- 使用"瓶颈产能 / 总工人数"而非"日产量 / (总工人数 × 有效工作时间)"
- 原因：产线实际产出受瓶颈限制，用瓶颈产能更准确反映"在瓶颈约束下的人均效率"
- 两种公式在数学上等价，但第一种更直观

**边界情况处理**：
- 产线为空：返回0.0
- 总工人数为0：返回0.0（避免除零错误）

### 测试建议

1. **UPPH计算测试**：
   - 创建包含多个工序的产线
   - 观察UPPH值是否合理（通常在30-80范围内）
   - 修改工人数量，观察UPPH变化

2. **KPI显示测试**：

### 技术细节

**对话框居中算法**：
```python
# 获取父窗口位置和大小
parent_x = parent.winfo_x()
parent_y = parent.winfo_y()
parent_width = parent.winfo_width()
parent_height = parent.winfo_height()

# 计算居中位置（相对于父窗口）
x = parent_x + (parent_width - dialog_width) // 2
y = parent_y + (parent_height - dialog_height) // 2

# 确保对话框不会超出屏幕
x = max(0, min(x, screen_width - dialog_width))
y = max(0, min(y, screen_height - dialog_height))
```

**画布自适应机制**：
- 监听`<Configure>`事件（画布大小变化时触发）
- 使用`after_idle()`延迟重绘，避免频繁触发
- 使用`after_cancel()`取消之前的延迟任务（防抖）
- 重新计算布局时使用实际画布尺寸
